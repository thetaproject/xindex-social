# Fonts

`GeneralSans-Variable.woff2` (Indian Type Foundry, Fontshare) is the brand face.
It is free for commercial use under the ITF Free Font License but is not an
open-source font, so it is not committed to this public repo.

Put the file here before running `render.py`. The weekly post agent downloads it
from the team's private Google Drive folder "XINDEX Social — private".
